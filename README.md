## Как работаем

Работаем в отдельных ветках; изменения через Pull Request в `main`.
Синхронизация дважды в неделю в виде созвонов в ВКС и дополнительном общение в чате команды. Корпоративные источники и замеры ведём обезличенно; личные данные кандидатов не публикуем.

## Сдача

```text
1. Все документы в ветке main
2. Проверка validate-docs.yml зелёная
3. data/meta.yml актуален: состав, роли, этап
4. Карточка на доске переведена в нужную колонку
5. В комментарии к Pull Request есть тег: "Сдаю этап N"
```
